# 🌍 IP Track - Node.js Version

**A Simple Public IP Information Lookup Tool built with Node.js**

Lookup any public IP address and get details like **Country, Region, City, ISP, Timezone, Coordinates**, and more.

</div>

---

## 📦 Update System Packages

```bash
apt update && apt upgrade
```

**What it does:**

- `apt update` → Downloads the latest package list from repositories.
- `apt upgrade` → Updates installed packages to their latest versions.

---

## 🛠 Install Required Packages

```bash
apt install nodejs git
```

**What it does:**

- `nodejs` → Installs Node.js to run the program.
- `git` → Installs Git to clone repositories from GitHub.

---

## 📥 Clone the Repository

```bash
git clone https://github.com/JubairSenseiDev/ip-track
```

**What it does:**

Downloads a copy of the project from GitHub to your local device.

---

## 📂 Open the Node.js Folder

```bash
cd ip-track/nodejs
```

**What it does:**

Changes the current working directory to the Node.js project folder.

> **cd** = Change Directory

---

## 📚 Install Node.js Dependencies

```bash
npm install
```

**What it does:**

Installs the required packages. No extra packages are needed — this program uses Node.js built-in modules (`fetch`, `net`, `fs`). If you get a "node:internal/modules/cjs/loader" error, make sure Node.js **18.0 or newer** is installed.

---

## ▶ Run the Program

```bash
node ip.js
```

**What it does:**

Runs the Node.js application.

> **node** is the command to run JavaScript files in Node.js.

---

## 📖 Command Reference

| Command | Description |
|---------|-------------|
| `apt update` | Refresh package lists |
| `apt upgrade` | Upgrade installed packages |
| `apt install` | Install new packages |
| `git clone` | Download a GitHub repository |
| `cd` | Change the current directory |
| `npm install` | Install Node.js packages |
| `node file.js` | Run a JavaScript file |

---

## 📋 Requirements

- Node.js 18.x or newer
- Git
- Internet Connection
