# 🌍 IP Track

**A Simple Public IP Information Lookup Tool built with Python**

Lookup any public IP address and get details like **Country, Region, City, ISP, Timezone, Coordinates**, and more.

---

## 📦 Update System Packages

```bash
apt update && apt upgrade
```

**What it does:**

- `apt update` → Downloads the latest package list from repositories.
- `apt upgrade` → Updates installed packages to their latest versions.

---

## 🛠 Install Required Packages

```bash
apt install python git
```

**What it does:**

- `python` → Installs Python to run the program.
- `git` → Installs Git to clone repositories from GitHub.

---

## 📥 Clone the Repository

```bash
git clone https://github.com/JubairSenseiDev/ip-track
```

**What it does:**

Downloads a copy of the project from GitHub to your local device.

---

## 📂 Open the Project Folder

```bash
cd ip-track
```

**What it does:**

Changes the current working directory to the project folder.

> **cd** = Change Directory

---

## 📚 Install Python Dependencies

```bash
pip install requests colorama
```

**What it does:**

Installs the required Python libraries.

- `requests` → Sends HTTP requests to APIs and websites.
- `colorama` → Adds colored text output in the terminal.

---

## ▶ Run the Program

```bash
python3 ip.py
```

**What it does:**

Runs the Python application.

> On most Linux distributions and Termux, `python3` is the recommended command.

---

## 📖 Command Reference

| Command | Description |
|---------|-------------|
| `apt update` | Refresh package lists |
| `apt upgrade` | Upgrade installed packages |
| `apt install` | Install new packages |
| `git clone` | Download a GitHub repository |
| `cd` | Change the current directory |
| `pip install` | Install Python packages |
| `python3 file.py` | Run a Python script |

- Python 3.x
